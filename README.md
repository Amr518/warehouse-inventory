# Warehouse Inventory Tablet App 📦
### منظومة الجرد المخزني الميداني لتابلت 10 بوصة مع التوافق الكامل مع Power BI

تطبيق ويب ميداني بدون ورق وبدون الحاجة إلى سيرفرات أو شبكة إنترنت (100% Offline-First) مصمم خصيصاً للجرد الفعلي للأصناف وقطع الغيار في المخازن الصناعية والدوائية (~25 قسم، كل قسم 10 إلى 20 درج).

- **🌐 Live Tablet Link:** [https://amr518.github.io/warehouse-inventory/](https://amr518.github.io/warehouse-inventory/)
- **📁 Source Code:** [https://github.com/Amr518/warehouse-inventory](https://github.com/Amr518/warehouse-inventory)

### المميزات الأساسية:
1. **واجهة مخصصة للشاشات اللمسية 10 بوصة:** أزرار كبيرة، خط واضح، دعم كامل للعربية (RTL).
2. **أمان البيانات والحفظ التلقائي الفوري (Auto-Save):** حفظ تلقائي في ذاكرة الجهاز (IndexedDB/localStorage) لحماية الداتا عند انقطاع الشحن أو إغلاق المتصفح.
3. **محرك بحث وفلترة بالقسم والدرج:** تنقل فوري بين أقسام وأدراج المخزن.
4. **تلوين بصري فوري:** مطابق (أخضر)، عجز (أحمر)، زيادة (أزرق)، لم يجرد (رمادي).
5. **نقل كامل الكمية لدرج آخر:** بضغطة زر واحدة واختيار الدرج الجديد.
6. **تصدير مهيأ ومباشر لـ Power BI:** ملف CSV مشفر بـ UTF-8 BOM لفتح التقارير باللغة العربية فوراً.
